About this data & what it does not tell you

This is a static snapshot of the available Copilot session history, captured October 20, 2026. It is not connected to a live API. Model figures are whole-session totals for session/model records whose latest usage falls within the rolling seven-day selection; activity outside the window may therefore be included. This is not a precise seven-day consumption report and may not include all your Copilot activity.

Usage units reflect the history store's sum of model billing multipliers. They are not dollar charges, an invoice, or a verified AI-credit balance. Cache reuse is cache-read tokens divided by input tokens, not a monetary savings estimate. Tool totals are independently selected by execution start time and cannot be attributed to the model filters from this snapshot.

Model filters and session search update the summary, model distribution, token breakdown, and session table together. Export downloads the currently selected session records plus the unfiltered tool snapshot and its scope. The embedded snapshot is readable by anyone with access to this file.
